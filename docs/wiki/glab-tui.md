# glab-tui

**glab-tui** is a terminal user interface (TUI) for GitLab and GitHub, built on
top of `glab` and `gh`. Browse issues, pull requests / merge requests,
pipelines, runners, and releases without leaving your terminal.

## Details

- **Version:** 0.8.4
- **License:** MIT
- **Upstream:** [GitHub - rcieri/glab-tui](https://github.com/rcieri/glab-tui)

## Installation

Once the ScientiOS repository is configured, install `glab-tui` via:

```bash
sudo xbps-install -Sy glab-tui
```
